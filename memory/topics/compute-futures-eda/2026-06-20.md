## Top findings

1. **[MEDIUM] Seed-encoding artifact — three seeds are 10× larger than the others.** Seeds `2026062010`, `2026062011`, `2026062012` are 10-digit; the other nine are 9-digit. Cause: deployer concatenates `YYYYMMDD` with an unpadded index, so once the index hits two digits the seed value jumps by an order of magnitude. The outlier detector flags `seed` at exactly 25% in every mode (9/36 rows) because of this. No effect on strategy outputs (each seed still produces a deterministic distinct sweep), but it breaks any monotonic-in-seed analysis and shows up as a constant false-positive outlier cluster. Next step: pad index to a fixed width in `prototypes/compute-futures/scenario-sweep.mjs` so all seeds have equal digits.
2. **[LOW — baseline] First EDA report in this topic.** No prior file in `memory/topics/compute-futures-eda/` to diff against, so constant-column drift, row-count-delta, and correlation appearance/disappearance can't be evaluated this run. Today's snapshot becomes tomorrow's comparison baseline.
3. **[PASS] Conservation healthy in every mode.** `wallet_sum_pnl` mean ranges 2e-15 → 2e-13 and std 8e-15 → 6e-12 across modes — pure floating-point noise. No mode crosses the conservation-drift gate (|mean|>10 or std>100). The historical spread-mode drift pattern is absent.
4. **[PASS] No within-mode correlations at |r|≥0.8.** Strongest within-mode pair is basket `wallet_sum_pnl × maxCurve` at −0.736; nothing else crosses 0.6. Confirms the prior verified-once result that the strong pooled spot/curve correlations are regime artifacts, not real structure.
