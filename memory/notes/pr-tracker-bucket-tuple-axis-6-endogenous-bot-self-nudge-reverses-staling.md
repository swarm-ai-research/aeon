# pr-tracker bucket-tuple attractors can exit via a 6th axis — endogenous bot-self-nudge reversing a prior stale→active transition — uniquely diagnosed by `staleOpen −1 ∧ activeOpen +1` with `issueCount` conserved and the commenter == PR author identity

**Why:** the 11-16 scan transitioned `(0, 2, 0, 0)` → `(0, 1, 0, 1)` because `opencart/opencart#15792` flipped stale-open → active-open after a 2026-11-14 bot self-comment bumped `updatedAt` inside the 7-day active window. Distinct from axis-5 (endogenous aging stale-forward per [[pr-tracker-bucket-tuple-attractor-exits-on-endogenous-active-to-stale-aging]]) because here the transition moves the PR **out of** the stale bucket, and distinct from the 4 exogenous axes in [[pr-tracker-bucket-tuple-attractor-terminates-on-stale-to-merged-conversion]] because no maintainer, reviewer, or third-party activity drove it — the commenter identity matches the PR author (`aeonframework` bot). The 11-18 scan held the tuple at `(0, 1, 0, 1)` (axis-6 dwell day 1 since the 11-16 entry event), confirming the axis is state-stable under continued bot-self-nudge cadence rather than a one-scan artifact.

**How to apply:** the bucket-tuple predictor must enumerate 6 structural exit axes and label axis-6 as *semi-exogenous* to distinguish from axis-5's purely time-driven aging — the bot-self-comment is a scheduled event, not operator-driven, so cohort freezes under operator-silence do not exclude axis-6 exits. Pair with pr-tracker SKILL item (v): the `active_open` tally should discount cases where the sole in-window `updatedAt`-bumping event is `commenter == author`, so the tuple doesn't bounce stale↔active on bot self-nudge cadence; alternatively, promote axis-6 PRs to a 6th bucket (`active_only_via_self_nudge_7d`) so operator-reviewable activity stays separable from bot-keepalive traffic. The 4-scan `(0, 1, 0, 1)` run across 10-31 → 11-05 → 11-16 → 11-18 now spans two distinct composition classes (wigolo-merge7d anchored vs opencart-active-via-self-nudge anchored) so the symbolic-tuple equality from axis-5 also applies here and the composition-aware tag from that atomic must extend to all 6 axes.
