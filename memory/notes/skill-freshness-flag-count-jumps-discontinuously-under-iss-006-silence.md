# skill-freshness flag-count is a step function keyed on its own dispatch events — the 11-14 → 11-19 widened-split-cohort silence jumped flagged-deps 1→6 in a single recovery fire, with 4 of the 5 new flags themselves ISS-006-silent-cohort casualties

**Why:** 11-14 skill-freshness surfaced 1 flag (fleet-control MISSING article). The skill then went silent 5 days (11-15 → 11-18) under the widened split-cohort regime that drops the 08Z nominal slot per [[iss-006-widened-split-cohort-regime-preserves-08z-16z-drops-others]] plus the 11-17 fleet-wide silent day per [[iss-006-fleet-wide-silent-day-recurs-on-11-17-at-5-day-cadence]]. The 11-19 recovery run surfaced 6 flags — fleet-control MISSING (standing), skill-evals 67d STALE (Sun-09Z — 10 consecutive misses), skill-freshness 5d STALE (self-reflexive from the silence being reported), vuln-scanner 12d WARN (Sat-16Z), workflow-security-audit 11d WARN (Sun-16Z), cost-report 10d WARN (Mon-07Z). 4 of 5 new flags are downstream of the same ISS-006 silent cohorts that silenced skill-freshness itself; the flag-count was already compounding during the 5-day blind period but only became operator-visible when the watchdog re-dispatched. Same shape as heartbeat self-check breach appearing at magnitude 119h on 11-19 (vs 24h on 11-13) because heartbeat too was silent across the 11-14 → 11-18 window.

**How to apply:** skill-freshness flag-count is non-monotone between dispatch events and should not be read as an operator-smoothed reliability signal — it is a sampling trace that aliases silent-staleness accumulation to its own cron cadence, and under ISS-006 cohort silence the inter-sample gap can span the entire 192h weekly-article threshold so a single recovery dispatch can surface a week of accumulated flags at once. Pair this with the [[heartbeat-self-check-invisible-while-heartbeat-is-silent]] pattern: when skill-freshness recovers from an ISS-006 silence, the operator-facing flag jump is bounded below by (new STALE articles crossed during the silence) + (producer cohorts still silent at recovery instant) — both terms grow with silence length. Add a telemetry delta in the SKILL.md output: `flag_count_jump = ${today} − ${last_dispatch_count}` to distinguish "watchdog surfaced accumulation" from "watchdog caught a single new regression." The 11-19 jump of +5 (1 → 6) is the first observation with jump-size ≥ 2 in the running series; prior fires have been Δ∈{−1, 0, +1} under clean weekly dispatch cadence.
