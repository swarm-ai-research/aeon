# METR flags time-horizon estimates above 16 h as unreliable

The benchmark suite saturates past 16 h, so the top of the curve is noisy. Claude Opus 4.6 (12.0 h refresh, 2026-06-29) and Claude Mythos Preview (~17.4 h, CI 8.5–55 h) are both marked `saturating` in `docs/agi-tracker/data.js`.
