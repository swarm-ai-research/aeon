## Triage

### Candidate 1 — `scripts/ensure_cloudflare_pages.py:26` — dynamic urllib use (WARNING)

Semgrep fires because `urllib.request.urlopen(req, …)` takes a dynamic URL. Reading the file:

- Maintainer-only deployment helper invoked from CI with `CLOUDFLARE_ACCOUNT_ID` + `CLOUDFLARE_API_TOKEN` repo secrets.
- Every URL is rooted at the constant `API = "https://api.cloudflare.com/client/v4"` with path segments derived from maintainer-supplied CLI args (`--project`, `--domain`, `--zone`).
- The `file://`-scheme escalation Semgrep warns about requires attacker-controlled URL scheme + host. Here both are fixed.
- No production code path passes external untrusted input here.

**Verdict:** false positive. Dropped.

### Candidate 2 — `zim/writer.go:138` — `md5.New()` in `WriteTo` (WARNING)

```go
sum := md5.New()
mw := io.MultiWriter(out, sum)
…
// The MD5 covers everything before it and is not itself hashed.
m, err := out.Write(sum.Sum(nil))
```

This is the trailing-MD5 footer mandated by the **ZIM file format** spec (the open container Kiwix/Wikipedia use for offline archives). Every ZIM reader expects to validate that exact field against the file body. Replacing MD5 here would break every downstream reader for zero security gain — it's an integrity checksum, not a signature, not a password hash, not anything adversaries are tasked with attacking.

**Verdict:** not a vulnerability — format compliance. Dropped.

### Candidate 3 — `zim/writer.go:410` — `md5.New()` in `deriveUUID` (WARNING)

```go
// deriveUUID makes the file deterministic: identical input yields an identical
// archive. It hashes every entry's key and content, so repacking the same
// mirror is idempotent and diffable.
func deriveUUID(ents []*entry) [16]byte {
    h := md5.New()
    …
}
```

ZIM header reserves exactly 16 bytes for the archive UUID — MD5 output width. The function is a content-addressed identifier, explicit per the comment: deterministic, idempotent, diffable. Not used as a security primitive.

**Verdict:** not a vulnerability — content fingerprint. Dropped.
