## Caveats and what the scan *didn't* cover

- **`nitro@3.0.260610-beta`** is a beta release. osv-scanner had no advisories for it at scan time. A future advisory landing on this specific beta tag would be the highest-priority follow-up — it's the only runtime dependency that ships to `eve` end users.
- **Code SAST** ran with the OSS Semgrep rulesets only (`p/security-audit + p/owasp-top-ten + p/secrets`). It does not include Semgrep Pro's TypeScript dataflow / cross-procedure reachability. A separate run with Semgrep Pro on the agent-tool execution path (`packages/eve/src/execution/sandbox/**`, `packages/eve/src/internal/nitro/**`, and the various `runtime/framework-channels/**` adapters) would be the next-most-useful pass — these are the highest-blast-radius surfaces in the framework.
- **Smart-contract scanner (slither)** was not applicable (no Solidity).
- **Sandbox**: prefetched scanner binaries are pinned (semgrep + slither via pip, trufflehog and osv-scanner via their installers). Versions used: trufflehog 3.95.6, osv-scanner latest at fetch time.
