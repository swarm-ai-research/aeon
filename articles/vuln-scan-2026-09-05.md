## Manual review — high-signal surfaces

Semgrep + OSV + TruffleHog under-cover the classes that dominate risk in an agent-runtime reference. Skimmed:

- **`commerce-common/commerce_common/mcp_server.py:29`** — `enforce_local_only_bind` refuses to bind off `{127.0.0.1, localhost, ::1}` unless an operator-set escape env var (documented with a warning about the missing inbound auth and required gateway) is `"1"`. Right default, right guardrail language.
- **`commerce-common/commerce_common/fencing.py`** — Extensive invisible-character normalization: soft hyphen, ZWJ/ZWNJ, bidi controls (0x202A-E, 0x2066-9, 0x061C), variation selectors (0xFE00-F, 0xE0100-1EF), tag characters (0xE0000-7F), BOM, deprecated format controls. Forged-turn regex requires blank-line boundaries so mid-sentence "human:" is not matched. All quantifiers bounded (`{0,8}`, `{1,40}`, `{1,200}`) to keep patterns linear on hostile input — the module docstring makes this explicit contract. Label uses `re.escape`, so an attacker-supplied tag name cannot inject a metacharacter into `_marker_pattern`.
- **`commerce-common/commerce_common/grounding.py:32`** — `re.escape(cleaned)` before every user-content regex build, no dynamic pattern injection.
- **`commerce-common/commerce_common/delegation.py`** — `DelegationContext` docstring explicitly bars a delegate from receiving `conversation` or `executor`, receives only `backend/config/session/state/emit_status/usage`, and cannot invoke other delegates. Clear tool-surface isolation.
- **Deserialization sweep** — no `yaml.load(` (unsafe), no `pickle.load`, no `marshal.load`, no `jsonpickle` anywhere in the tree.
- **Command execution sweep** — `subprocess.` / `os.system` / `eval(` / `exec(` only in `scripts/` (dev orchestration) and `tests/` (fixtures), not in `commerce-common/`, `shopping-agent/`, `merchant-agent/`, or `examples/**/api/**`.
- **HTTP fetches** — `urlopen` / `httpx` / `requests` only in `scripts/`, `tests/`, and `conftest.py`. Merchant API surfaces in `examples/**/api/` are in-process fixtures — no outbound HTTP that could SSRF against an attacker-supplied URL.
