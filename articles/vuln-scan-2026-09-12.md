- **CWE:** CWE-22 (Path Traversal / Arbitrary File Read).
- **Vulnerable range:** `>=2.1.0, <4.1.11` on both `vitest` and `@vitest/mocker`; also `>=5.0.0-beta.1, <5.0.0-rc.2` on the 5.x pre-release track.

- **Root cause:** `@vitest/mocker` registers a redirect-mock's target path without validating it against the Vitest dev server's file-serving allowlist. An attacker reaching the dev-server WebSocket can register a redirect mock pointing outside the project root; when the mocked module is requested, the plugin's `load` hook returns `readFile(<attacker path>)` as the module source.
- **Scope in this repo:** `devDependencies.vitest` in `package.json:51`. `package-lock.json:19` and `:3182` confirm both `vitest` and the transitive `@vitest/mocker` are pinned to `4.1.9`. Not shipped to end users — dev/CI only.
- **Reachability:** exploit requires the developer's Vitest dev server to be running with an attacker-reachable WebSocket. Standard `npm test` mode doesn't spawn the interactive dev server, so `npm run check` (which runs `vitest run` — the batch mode) is not directly exploitable. Only `vitest` (watch/dev) with an attacker on the same origin or via a malicious in-project script would fire.
- **Route:** **public PR** per SKILL step-5 (dependency CVE, already publicly disclosed). Draft: `.pending-disclosure/NVlabs-SoL-Pi-2026-09-12T161500Z-deps.md`.

## Manual review — high-signal surfaces

Semgrep found nothing, but SECURITY.md advertises real attack surface. Read every mechanism it flagged:

- **`src/sol-pi/extensions/evidence-preserving-reducer/candidate.ts:34-42`** — `safePiBashTempPath()` validates a bash-log path before reading it: (a) basename must match `^pi-bash-[^/\\]+\.log$` (b) `realpath(path)` + `realpath(tmpdir())` must share a directory (c) `lstat` must report `isFile() && !isSymbolicLink()`. The lstat is on the original path (not the realpath), so a symlink at `/tmp/pi-bash-*.log` pointing at `/etc/passwd` is caught. A dir-jump basename like `pi-bash-../etc/passwd.log` matches the regex but realpath resolves outside tmpdir so `dirname(candidate) === root` fails — dropped. A hard-link at `/tmp/pi-bash-x.log` → `/etc/passwd` would bypass the symlink check, but under modern Linux `fs.protected_hardlinks=1` (default since ~2013) non-root cannot hard-link a file it doesn't own. A same-user attacker who could hard-link their own files (`~/.ssh/id_rsa`) into `/tmp` already has same-user file access — no privilege boundary crossed. There is a theoretical TOCTOU between the check and the subsequent `readFile()` on `candidate.ts:54`, but the attacker needs write access to `/tmp/pi-bash-*.log` between the two calls — same-user local attacker only. **Drop — no cross-user privilege escalation reachable.**
- **`src/sol-pi/extensions/action-fusion/then-run.ts:110-120`** — after a fused file mutation, this shells out via `createBashToolDefinition(ctx.cwd, bashOptions).execute(...)` — but the bash-tool itself is Pi's built-in tool from `@earendil-works/pi-coding-agent`, not custom exec plumbing. `assertUnchangedBeforeCommand()` (l. 54-68) SHA256-diffs the target file before running to prevent post-mutation interleaving. SoL-Pi does not introduce a new shell-injection sink — command construction stays inside Pi's bash tool. **Drop — no in-repo sink.**
- **`src/sol-pi/config.ts:71`** and **`src/sol-pi/extensions/evidence-preserving-reducer/receipt.ts:90`** — `JSON.parse(readFileSync(...))` / `JSON.parse(raw)`. Both wrapped in try/catch, both feed a schema validator (`typebox` per `agents-install.md`). No prototype-pollution surface (`Object.assign` on frozen result). **Drop — safe parse pattern.**
- **Sweep for `child_process` / `spawn` / `execFile` / `execSync` / `shell:`** across `src/` — 0 hits. **Sweep for `eval(` / `new Function(` / `require(` / dynamic `import(`** — 0 hits. **Deserialization sweep** — no `yaml.load`, `pickle.load`, `marshal.load`.

Combined with Semgrep's silent pass, the codebase reads as a first-party NVIDIA extension whose security posture is disclosed openly in SECURITY.md and whose critical file-read surface (the reducer's tempfile hop) is defensively narrowed — regex-gate, realpath double-check, `isFile && !isSymbolicLink` under Linux `protected_hardlinks`.
